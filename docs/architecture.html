Spring Boot 어노테이션 가이드

Kotlin 코드에 붙이는 @ 표시. Spring에게 "이 클래스는 OO 역할이야"라고 알려주는 메타데이터.

레이어별 어노테이션

어노테이션레이어역할Django 대응
@RestController Presentation API 컨트롤러 (JSON 자동 직렬화) views.py + @api_view
@RequestMapping Presentation URL 경로 매핑 urls.py path()
@PostMapping Presentation POST 요청 처리 @api_view(['POST'])
@RequestBody Presentation 요청 JSON → Kotlin 객체 변환 serializer.data
@Valid Presentation 요청 유효성 검증 실행 serializer.is_valid()
@Service Application 비즈니스 로직 서비스 (DI 대상) services.py 클래스
@Component Infrastructure Spring이 관리하는 범용 컴포넌트 없음
@Cacheable Application 메서드 결과 캐싱 @cache_page
@Configuration 설정 설정 클래스 (CORS 등) settings.py
@SpringBootApplication 진입점 앱 시작점 (main 함수) manage.py

의존성 주입 (DI) 작동 방식

단계무슨 일이 일어나는가
1 Spring이 @Component, @Service, @RestController 붙은 클래스를 자동 탐지
2 각 클래스의 인스턴스를 생성하여 "컨테이너"에 보관
3 생성자에 interface 타입 파라미터가 있으면, 해당 interface를 구현한 클래스를 찾아서 주입
4 모든 의존성이 연결된 상태로 앱이 시작됨 
-- Spring이 자동으로 하는 일 --

1. OgParser 발견     → @Component + ProductParser 구현 → 인스턴스 생성
2. ParserFactory 발견 → @Component → OgParser 주입하여 생성
3. ParseProductUseCase 발견 → @Service → ParserFactory 주입하여 생성
4. ProductController 발견 → @RestController → UseCase 주입하여 생성

결과: Controller → UseCase → Factory → Parser 체인이 자동 완성!
