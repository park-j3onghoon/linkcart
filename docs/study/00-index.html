최근 업데이트: 2026-04-20 — 03/04/06/07/08/15 챕터에 "심화 Q&A" 섹션 보강 (Bean/IoC/DI/어노테이션/@Value/Kotlin : 문법/Entity vs VO/Port vs Repository/JPA 어노테이션/Spring Data JPA/HikariCP/open-in-view/레이어별 테스트/Django 비교)

학습 철학 (tnear-backend-prep-test.md 인용)

세 가지 원칙
  1. 이미 있는 Python/Django 실무 강점을 버리지 않는다
  2. 그 강점을 Kotlin/Spring 문법과 구조로 번역한다
  3. linkcart를 티니어가 좋아할 만한 방향으로 진화시킨다

티니어 공고 요구 역량 7종

① Kotlin/Java + Spring 기반 서버 개발
② 안정적인 운영과 장애 대응 (24/365)
③ 글로벌 멀티 플랫폼 API 설계
④ AWS/로그/모니터링/알림에 대한 운영 관점
⑤ RDBMS/NoSQL 데이터 모델링
⑥ 테스트, 코드 리뷰, 협업
⑦ 작게 만들고 빨리 검증하는 실행 방식
